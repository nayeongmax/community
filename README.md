# 커뮤니티 플랫폼 (Community)

누구나 커뮤니티를 개설하고, 게시판을 열고, 자유롭게 글을 쓰고 소통할 수 있는
**오픈 커뮤니티 플랫폼**입니다. (네이버 카페 + 디시인사이드 / 뽐뿌 / 보배드림 스타일)

## ✨ 주요 기능

- **회원가입 / 로그인** — 이메일 + 닉네임
- **커뮤니티 개설** — 누구나 이름·카테고리·소개를 정해 커뮤니티를 만들 수 있음
- **커뮤니티 탐색** — 카테고리 필터 · 검색 · 인기순/활발한/최신 정렬
- **게시판** — 커뮤니티마다 공지사항·자유게시판 기본 생성, 운영자가 게시판 추가/삭제
- **가입 / 탈퇴** — 멤버 등급(운영자 / 관리자 / 멤버)
- **글쓰기 · 글목록 · 글상세** — 조회수 카운트, 게시판별 목록
- **사진·동영상·링크 첨부** — 글에 여러 개 붙일 수 있음
- **글 수정/삭제** — 작성자는 수정·삭제, 운영진은 모든 글 삭제
- **커뮤니티 꾸미기** — 대표 이미지(사진/이모지) · 타이틀 이미지 (네이버 카페 스타일)
- **댓글** — 작성 / 삭제 / 좋아요
- **추천 / 비추천** — 디시 스타일 개추/비추
- **마이페이지** — 내가 가입/개설한 커뮤니티 목록
- **커뮤니티 관리** — 운영자용 게시판·멤버 관리
- **광고 배너** — 홈에 한 줄 2개씩 노출 · 이미지 등록 · 노출 순서 변경 (`/ads`)
- **🎮 게임 센터 + 익명 자유게시판** (`/games`) — 아래 참고

## 🎮 게임 센터 · 익명 자유게시판 (`/games`)

한 페이지 위쪽에는 **바로 즐기는 미니게임 12종**, 아래쪽에는 **익명 자유게시판**이 있습니다.
로그인 없이 클릭만으로 플레이할 수 있고, 점수는 XP 로 쌓여 레벨이 올라갑니다.

| 게임 | 조작 | 게임 | 조작 |
| --- | --- | --- | --- |
| 🎯 다트 던지기 | 클릭 (바람 보정) | 🐍 스네이크 | 방향키·WASD·화면 버튼 |
| 🎡 행운 룰렛 | 클릭 | 🧱 브레이크아웃 | 마우스 |
| 🎰 슬롯머신 | 클릭 (5열 3행 · 라인 5개) | 🎈 풍선 터뜨리기 | 클릭 (30초) |
| 🎟 긁는 복권 | 드래그로 긁기 | ⚡ 반응속도 | 클릭 (5라운드) |
| 🐤 파이프 통과 | 클릭·스페이스 | 🃏 짝 맞추기 | 클릭 |
| 🧠 일반상식 퀴즈 | 4지선다 (문제당 15초) | 🃏 카지노 OX 퀴즈 | O/X 클릭 (룰·확률·상식) |

- 슬롯머신은 5열 3행에 당첨 라인 5개(가운데·윗줄·아랫줄·V자·∧자)가 있고,
  왼쪽부터 3개 이상 같은 그림이면 당첨입니다. (4개 3배 · 5개 8배)
- 점수 → XP 환산과 최고기록은 게임마다 저장되고, 300 XP 마다 레벨이 1 오릅니다.
- 퀴즈 문항은 `src/games/quizData.ts` 한 곳에 모여 있어 문제 추가/수정이 쉽습니다.
  상식 퀴즈는 빨리 맞힐수록, 카지노 OX 퀴즈는 3연속 정답부터 보너스 점수가 붙습니다.
  카지노 OX 는 **룰 · 확률·배당 · 상식·역사** 세 갈래의 카지노 문항만 다룹니다.
- 한 판이 끝나면 **게시판에 점수 자랑하기** 버튼으로 결과가 담긴 글을 바로 쓸 수 있습니다.
- 게시판은 **완전 익명**입니다. 글마다 랜덤 닉네임(예: "지나가던 감자")이 붙고,
  카테고리(자유·유머·질문·게임·고민·정보) · 정렬(최신/인기/댓글순) · 검색 · 댓글 · 추천을 지원합니다.
- 삭제는 글 작성 시 정한 **숫자 4자리 비밀번호**로 합니다. (같은 브라우저에서 쓴 글은 비번 없이 삭제)

### 🏝 마이 랜드

게임을 하고 게시판에서 활동할수록 쌓이는 **랜드 포인트**로 내 마을이 6단계까지 자랍니다.

| 단계 | 필요 포인트 | 모습 |
| --- | --- | --- |
| 1 빈 터 | 0 | 팻말 하나뿐인 땅 |
| 2 초가집 | 120 | 첫 집과 모닥불 |
| 3 마을 어귀 | 350 | 이웃집 · 나무 · 길 |
| 4 상점 거리 | 800 | 가게 두 채 · 가로등 |
| 5 아파트 단지 | 1,600 | 고층 건물 · 크레인 |
| 6 랜드마크 타워 | 3,000 | 황금 타워 · 불꽃놀이 |

포인트는 **게임 XP 1점 = 1P · 글 25P · 댓글 10P · 내 글이 받은 추천 6P** 로 쌓이고,
바로 다음 단계 건물은 흐린 실루엣으로 미리 보입니다. (`src/components/MyLand.tsx`)

## 🖼 미디어 · 권한

### 커뮤니티 꾸미기 (운영자)

`관리` → **커뮤니티 꾸미기** 에서 두 가지를 바꿀 수 있습니다.

- **대표 이미지** — 사진을 올리거나 이모지 중에서 고릅니다. 사진이 있으면 사진이 우선입니다.
- **타이틀 이미지** — 커뮤니티 홈 맨 위에 걸리는 가로 배너 (권장 1200×300)

### 글 첨부

글쓰기에서 **사진 · 동영상 · 링크**를 여러 개 붙일 수 있습니다.

- 사진: 가로 1400px 로 줄여 저장
- 동영상: 40MB 까지 · 글에서 바로 재생
- 링크: 주소와 이름을 넣으면 카드 형태로 보입니다

이미지·동영상은 용량이 커서 **IndexedDB**(`src/lib/media.ts`)에 저장하고,
글·커뮤니티에는 파일 id 만 남깁니다. 실제 서비스로 갈 때는 `putMedia` / `mediaUrl`
두 함수만 스토리지 업로드로 바꾸면 됩니다.

### 권한

| | 수정 | 삭제 |
| --- | --- | --- |
| 글 작성자 | ✅ | ✅ |
| 커뮤니티 운영자·관리자 | — | ✅ (모든 글) |
| 그 외 | — | — |

권한 검사는 화면이 아니라 데이터 계층(`store.updatePost` / `store.deletePost`)에서 합니다.

## 🔎 검색 노출 (`/seo`)

네이버·구글 검색에 **글 하나하나**가 잡히도록 준비해 둔 부분입니다.

### 글마다 이미 붙는 것

| 항목 | 내용 |
| --- | --- |
| 고유 주소 | `/c/<커뮤니티>/post/<글번호>` |
| `<title>` | 글 제목 + 사이트 이름 |
| `description` | 본문 앞 155자 요약 |
| `canonical` | 같은 글이 여러 주소로 중복 색인되지 않게 |
| 오픈그래프 | 카카오톡·페이스북 공유 카드 |
| `keywords` | 커뮤니티 이름 · 게시판 · 글에 단 태그 |
| 구조화 데이터 | `DiscussionForumPosting` + `BreadcrumbList` (JSON-LD) |

구현은 `src/lib/seo.ts` 의 `useSeo()` 한 곳이고, 각 페이지에서 호출합니다.

### 제출 파일 만들기

`/seo` 화면에서 지금 저장된 글을 모아 내려받을 수 있습니다.

- `sitemap.xml` — 커뮤니티·글 전체 주소 (글은 수정 시각을 `lastmod` 로)
- `rss.xml` — 최근 글 50개 (네이버 서치어드바이저 RSS 제출용)
- `robots.txt` — 네이버 `Yeti` 허용, 관리·작성 화면은 색인 제외

사이트 주소·네이버/구글 소유확인 코드도 여기서 넣습니다.

### ⚠️ 실제 노출까지 남은 일

**지금 구조로는 어떤 검색엔진에도 올라가지 않습니다.** 두 가지가 막고 있습니다.

1. **글이 브라우저에만 있습니다.** 검색로봇은 남의 브라우저 안을 볼 수 없습니다.
   → Supabase 등 백엔드를 붙여 글을 서버에 저장해야 합니다. (`supabase-schema.sql` 준비됨)
2. **네이버 검색로봇은 자바스크립트를 거의 실행하지 않습니다.**
   이 앱은 브라우저에서 화면을 그리는 SPA 라, 로봇이 받는 HTML 은 빈 껍데기입니다.
   → 글 주소로 요청했을 때 **서버가 완성된 HTML 을 돌려주도록**(SSR/SSG) 옮겨야 합니다.
   Next.js 로 옮기거나, 글마다 정적 HTML 을 미리 만들어 두는 방식 모두 가능합니다.

구글은 자바스크립트를 실행하므로 1번만 해결해도 색인될 가능성이 있지만,
**네이버가 목적이라면 2번이 필수**입니다.

## 📣 광고 배너 (`/ads`)

홈 피드 위에 **한 줄에 2개씩** 배너가 노출됩니다.

- 이미지를 고르거나 끌어다 놓으면 브라우저에서 **가로 900px 로 줄여** 저장합니다
  (원본을 그대로 담으면 저장 공간이 금방 찹니다 · 권장 비율 2:1)
- 배너마다 이름 · 연결 주소 · 노출 on/off 를 지정할 수 있습니다
- 목록의 **↑ ↓ 로 순서를 바꾸면 그대로 노출 순서**가 됩니다
- 외부 링크에는 `rel="noopener noreferrer sponsored"` 가 붙습니다

데이터 계층은 `src/lib/ads.ts` 한 곳이라, 실제 서비스에서는 이미지 업로드만
스토리지(S3·Supabase Storage 등)로 바꾸면 됩니다.

### 🎨 디자인 기준

커뮤니티 화면(밝은 테마)과 게임 랜드(어두운 테마)를 **잉크 남색 + 금색 포인트** 한 가족으로 묶었습니다.
색으로 구분하던 자리를 여백·굵기·얇은 경계선으로 바꿔 화면이 차분해지도록 정리했습니다.

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `ink` | `#14172b` | 제목 · 기본 버튼 · 선택된 항목 |
| `ink-soft` / `ink-mute` / `ink-faint` | `#252a45` / `#6b7180` / `#9aa0b0` | 본문 · 보조 · 흐린 글씨 |
| `hair` | `#e6e8ef` | 1px 경계선 (그림자 대신) |
| `ground` | `#f7f8fa` | 페이지 바탕 · 입력칸 |
| `gold` / `gold-soft` / `gold-wash` | `#a87b22` / `#f5c765` / `#fdf6e6` | 순위·공지 같은 포인트 |

토큰은 `index.html` 의 Tailwind 설정에 정의돼 있어 `bg-ink`, `text-ink-mute`, `border-hair` 처럼 씁니다.

- 색 블록으로 채우던 주제 타일·커뮤니티 커버는 흰 카드 + 얇은 경계선으로 바꿨습니다.
- 내비게이션은 단색 아이콘(`src/components/Icon.tsx`), 주제·커뮤니티 같은 콘텐츠만 이모지를 씁니다.
- 닉네임·커뮤니티 색은 채도를 낮춰(`colorFromString`) 화면이 알록달록해지지 않게 했습니다.
- 아바타는 이름 첫 글자 대신 **이모지**를 씁니다. 직접 고르지 않으면 이름에서
  항상 같은 이모지가 배정됩니다. (`src/lib/emoji.ts`)
- 왼쪽 내비는 `홈 · 탐색 · 구독 · 게임 랜드 · 채팅` 아래에 **누구나 모임**
  (`주제별 · 지역별 · 대표커뮤니티 · 팬클럽 · 랭킹`)을 둡니다.

### 🌌 화면

게임 랜드(`/games`)는 공통 레이아웃과 분리된 **밤하늘 테마 전용 페이지**입니다.

- 별이 깜빡이는 캔버스 배경 · 마우스를 따라 움직이는 빛무리와 포인터 고리

- 별은 포인터 방향으로 살짝 밀리는 시차 효과가 있습니다

`src/games/` 에 `GameProps` 를 받는 컴포넌트를 만들고 `src/games/index.ts` 의 `GAMES` 배열에
`GameDef` 하나만 추가하면 카드·모달·기록·XP 가 자동으로 연결됩니다.

```tsx

```

## 🗄 데이터 저장 방식

- **기본(데모) 모드**: 브라우저 `localStorage` 에 저장 — 백엔드 없이 완전 동작.
  단, 데이터는 접속한 브라우저 안에서만 공유됩니다.
- **프로덕션(다중 사용자) 모드**: `supabase-schema.sql` 을 Supabase 에서 실행하고
  `.env` 에 아래 값을 넣으면 여러 사용자가 공유하는 실제 백엔드로 전환할 수 있습니다.

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key
```

데이터 접근 계층은 `src/lib/store.ts` 한 곳에 모여 있고 모든 함수가 `Promise` 를
반환하도록 설계돼 있어, 함수 내부만 Supabase 쿼리로 교체하면 UI 코드 수정 없이
전환됩니다.
